# AB Bespoke Home

Astro homepage design for AB Bespoke Home, Sacramento.

## Development

Requires Node.js 22.

```sh
npm ci
npm run dev
```

## Netlify

Import this repository into Netlify. Production branch: `main`. Build command: `npm run build`. Publish directory: `dist`. Configuration is provided in `netlify.toml`.

## Preview status

This is the initial homepage design. Service and contact links lead to the current ab-bespoke.com site. The page includes a noindex directive while the design is under review; remove it before final public launch. Desktop/mobile visual QA remains outstanding.
